# 15. 3Sum

https://leetcode.com/problems/3sum/description/

## 문제

Given an integer array nums, return all the triplets [nums[i], nums[j], nums[k]] such that i != j, i != k, and j != k, and nums[i] + nums[j] + nums[k] == 0.

Notice that the solution set must not contain duplicate triplets.

- Example 1:
  Input: nums = [-1,0,1,2,-1,-4]
  Output: [[-1,-1,2],[-1,0,1]]
  Explanation:
  nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0.
  nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0.
  nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0.
  The distinct triplets are [-1,0,1] and [-1,-1,2].
  Notice that the order of the output and the order of the triplets does not matter.

- Example 2:
  Input: nums = [0,1,1]
  Output: []
  Explanation: The only possible triplet does not sum up to 0.

- Example 3:
  Input: nums = [0,0,0]
  Output: [[0,0,0]]
  Explanation: The only possible triplet sums up to 0.

## 내 풀이(TS)

```ts
function threeSum(nums: number[]): number[][] {
  const output: number[][] = [];
  const numMap = new Map<number, number>(); // number, count
  const numArr: number[] = [...new Set(nums)];

  for (let i: number = 0; i < nums.length; i++) {
    numMap.set(nums[i], numMap.has(nums[i]) ? numMap.get(nums[i]) + 1 : 1);
  }

  for (let i: number = 0; i < numArr.length; i++) {
    const num = numArr[i];
    if (num === 0 && numMap.get(num) >= 3) {
      output.push([0, 0, 0]);
    }
    if (num !== 0 && numMap.get(num) >= 2 && numMap.has(num * -2)) {
      output.push([num, num, num * -2]);
    }

    const target: number = 0 - num;
    const numSet = new Set<number>();
    for (let j: number = i + 1; j < numArr.length; j++) {
      const num2 = numArr[j];
      const target2: number = target - num2;
      if (numSet.has(target2)) {
        output.push([num, num2, target2]);
      }
      numSet.add(num2);
    }
  }

  return output;
}
```

1. Map<number, count>와 중복제거된 numArr을 조합해서 [x, x, -2x] 케이스와 서로 다른 세 숫자 케이스를 분리함

- 시간복잡도: O(n^2)
- 공간복잡도: O(n)

## 추천 풀이: 정렬 + 투 포인터

```ts
function threeSum(nums: number[]): number[][] {
  nums.sort((a, b) => a - b);
  // 정렬을 통해 합의 크기를 보고 left, right 중 무엇을 움직일지 판단

  const result: number[][] = [];

  for (let i = 0; i < nums.length - 2; i++) {
    if (i > 0 && nums[i] === nums[i - 1]) {
      continue;
    }
    // 중복 방지를 위해 앞의 i와 같으면 건너뜀

    if (nums[i] > 0) {
      break;
    }
    // 정렬되어 있으므로 0보다 크면 3Sum이 무조건 양수

    let left = i + 1;
    let right = nums.length - 1;

    while (left < right) {
      const sum = nums[i] + nums[left] + nums[right];

      if (sum === 0) {
        result.push([nums[i], nums[left], nums[right]]);

        left++;
        right--;

        while (left < right && nums[left] === nums[left - 1]) {
          left++;
        }
        // left 중복 제거

        while (left < right && nums[right] === nums[right + 1]) {
          right--;
        }
        // right 중복 제거
      } else if (sum < 0) {
        left++;
      } else {
        right--;
      }
    }
  }

  return result;
}
```

- nums[i]를 하나 고정한 뒤, 나머지 두 수의 합이 -nums[i]가 되도록 양 끝에서부터 left, right를 움직이는 방법

- 시간복잡도: O(n^2)
- 공간복잡도: O(1) 수준

## Python 풀이코드

```py
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        result = []
        nums.sort()

        for i in range(len(nums)-2):
            if i > 0 and nums[i] == nums[i-1]:
                continue

            if nums[i] > 0:
                break

            left = i + 1
            right = len(nums) - 1

            while left < right:
                sum_3 = nums[i] + nums[left] + nums[right]

                if sum_3 == 0:
                    result.append([nums[i], nums[left], nums[right]])

                    left += 1
                    right -= 1

                    while left < right and nums[left] == nums[left - 1]:
                        left += 1
                    while left < right and nums[right] == nums[right + 1]:
                        right -= 1

                elif sum_3 < 0:
                    left += 1
                else:
                    right -= 1

        return result
```
