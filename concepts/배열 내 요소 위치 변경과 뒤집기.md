# 배열 요소 순서 변경과 뒤집기

알고리즘 문제에서는 배열 내부의 요소 위치를 바꾸거나 특정 구간을 뒤집는 연산을 자주 사용한다.

---

## 1. 두 요소의 위치 바꾸기

### TypeScript

기본적인 방법:

```ts
const temp = nums[i];
nums[i] = nums[j];
nums[j] = temp;
```

Destructuring Assignment를 사용하면 더 간단하게 작성할 수 있다.

```ts
[nums[i], nums[j]] = [nums[j], nums[i]];
```

### Python

기본적인 방법:

```python
temp = nums[i]
nums[i] = nums[j]
nums[j] = temp
```

Unpacking을 사용하면 더 간단하게 작성할 수 있다.

```python
nums[i], nums[j] = nums[j], nums[i]
```

---

## 2. 배열 전체 뒤집기

### TypeScript

```ts
nums.reverse();
```

`reverse()`는 원본 배열을 직접 수정한다.

### Python

```python
nums.reverse()
```

Python의 `list.reverse()` 역시 원본 리스트를 직접 수정하며 반환값은 `None`이다.

---

## 3. 특정 구간 뒤집기

특정 구간을 **O(1) 추가 공간**으로 뒤집으려면 Two Pointer 방식으로 직접 swap하면 된다.

### TypeScript

```ts
let left = start;
let right = end;

while (left < right) {
  [nums[left], nums[right]] = [nums[right], nums[left]];

  left++;
  right--;
}
```

### Python

```python
left = start
right = end

while left < right:
    nums[left], nums[right] = nums[right], nums[left]

    left += 1
    right -= 1
```

### 복잡도

구간의 길이를 `k`라고 하면:

- 시간복잡도: `O(k)`
- 공간복잡도: `O(1)`

---

## 정리

| 목적              | TypeScript                    | Python                    |
| ----------------- | ----------------------------- | ------------------------- |
| 두 요소 swap      | `[a[i], a[j]] = [a[j], a[i]]` | `a[i], a[j] = a[j], a[i]` |
| 전체 reverse      | `arr.reverse()`               | `arr.reverse()`           |
| 특정 구간 reverse | Two Pointer + Swap            | Two Pointer + Swap        |

특히 LeetCode에서 `in-place`, `O(1) extra space` 조건이 있다면 특정 구간을 뒤집을 때 Two Pointer 방식이 가장 안전하다.
